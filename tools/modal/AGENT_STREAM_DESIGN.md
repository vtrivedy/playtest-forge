# Detached agent streams

Use one detached Modal app per named stream (2 CPU, 4 GiB, 2.5-hour timeout), with Node 22 and pinned Codex/Claude CLIs. Follow Harbor's runtime auth injection rather than baking credentials into an image. Run agent subprocesses as an unprivileged user so Claude permission bypass works. Clone the private repo over HTTPS using GIT_ASKPASS and a runtime GitHub token, create/resume only s2-* branches. Never put tokens in git URLs or command arguments.

Local entrypoint creates a separate detached worker app with function.spawn; registry in fox-agent-stream-registry holds stream name, call/app IDs and state. Claim names atomically; reject duplicates. --list shows registry, --stop requests graceful termination; after cancellation use documented modal app stop if needed. Timed shutdown terminates the subprocess group, pushes committed work, flushes persistent logs, removes auth and checkout. Every minute flush logs to fox-agent-streams volume, every five minutes push existing commits without force. Preserve a final status and push SHA. No auto-committing dirty work or merging main in the supervisor.

Secrets come from existing ~/.codex/auth.json, ~/.config/secrets/claude.env and gh auth token; allowlisted names only. They enter the worker through ephemeral Modal Secrets and auth is written mode 0600 outside repo/volume. Redact literal secret values from captured child output. Agents are authorized to read credentials for CLI auth; this is not isolation from malicious agent commands. Logs and the mounted volume must never contain auth files. GPU work is requested through capture-request.json on the volume for the local driver, avoiding copying Modal account credentials into workers.

Verification: import/compile; validation and lifecycle tests using mocked Modal/subprocess; real remote-route stream authenticates, clones, installs deps, emits log and pushes a branch. Opus reviews credential handling, detachment, stop and cleanup. This is infrastructure-only; remote route-art changes require GPU playtest and screenshot review separately.
