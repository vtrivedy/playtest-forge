# Smoke Dodge

- **Core verb:** Dodge — move to avoid hazards.
- **Rules:** WASD/arrows move on a circular arena; 8 bouncing hazards; 3 hits = lose.
- **Win / lose:** Survive 20s / take 3 hits. Target session ~20s.
- **Difficulty ramp:** Constant hazard count; player speed slightly favors survival for smoke test reliability.
- **Feedback / juice:** Hit screenshake + particle burst; win burst; emissive PBR player/hazards; bloom.
- **Visual references:** Clean neon arena, dark studio HDRI, readable silhouettes.
